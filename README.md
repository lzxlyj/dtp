# 黑暗三角人格测试网页 - 修改说明

## 修改内容

### 雷达图合并
- 将原来的两个雷达图（用户分数分布和人群排名对比）合并为一个雷达图
- 使用不同颜色区分两个数据集：
  - 用户分数：紫色（#9D4EDD）
  - 人群排名：红色（#FF6384）
- 添加了图例，显示两个数据集的标签

### 排名数据调整
- 修改了排名数据生成逻辑，确保排名数据在每个维度上都不超过用户分数
- 当排名分数超过用户分数时，自动调整为用户分数的0.5-1倍之间的随机值
- 这样保证了排名数据始终低于或等于用户分数，符合"用户排名雷达图高于或最大时等于用户分数"的要求

### 界面优化
- 调整了雷达图容器的布局，使其在页面中居中显示
- 增加了图例的可见性，提高了用户体验
- 保持了原有的暗黑风格设计

## 文件说明

- `index.html`: 主文件，包含完整的HTML结构、CSS样式和JavaScript逻辑
- `test.html`: 测试文件，用于验证雷达图功能
- `README.md`: 修改说明文档

## 使用方法

1. 打开 `index.html` 文件
2. 输入有效的兑换码（如：3VvPOktO6）
3. 点击"开始测试"按钮
4. 完成42道测试题
5. 查看结果页面中的合并雷达图，显示用户分数和排名对比
