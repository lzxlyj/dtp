📋 问题描述

问题：详细维度分析功能无法正确显示分析文本 已修复
根本原因：元素ID匹配错误
// 问题代码（修复前） // 调用时传递驼峰式命名 updateDimensionUI('selfInterest', score); // 但HTML元素使用连字符格式 <div id="self-interest-analysis"></div> // 导致无法找到对应的分析文本元素

🔧 修复方案

解决方案：在updateDimensionUI函数中添加驼峰式到连字符格式的转换
function updateDimensionUI(dimensionKey, score, elementIdPrefix) { // 将驼峰式转换为连字符格式 const kebabCasePrefix = dimensionKey.replace(/([a-z0-9])([A-Z])/g, '$1-$2').toLowerCase(); const analysisElementId = elementIdPrefix || `${kebabCasePrefix}-analysis`; // 现在可以正确找到元素 const analysisElement = document.getElementById(analysisElementId); // 更新分析文本... }
